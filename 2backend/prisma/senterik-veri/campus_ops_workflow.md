# Campus Ops – Request Workflow & Status System

## Overview
This document defines:
- Request lifecycle
- Workflow approval chains
- Status management
- Role-based approval system

---

## Core Architecture

Request
→ Workflow (steps)
→ Status (global + step)

---

## Global Request Status

DRAFT
SUBMITTED
IN_REVIEW
RETURNED_FOR_REVISION
APPROVED
REJECTED
IN_PROGRESS
SCHEDULED
RESOLVED
COMPLETED
CANCELLED
CLOSED

---

## Workflow Step Status

PENDING
ACTIVE
APPROVED
REJECTED
RETURNED
SKIPPED

---

## General Lifecycle

DRAFT → SUBMITTED → IN_REVIEW → APPROVED / REJECTED → IN_PROGRESS → COMPLETED → CLOSED

---

## Request Workflows

### DOCUMENT_REQUEST
STUDENT → DOCUMENT_OFFICER → FACULTY_SECRETARY → COMPLETED

Status:
DRAFT → SUBMITTED → IN_REVIEW → APPROVED → IN_PROGRESS → COMPLETED → CLOSED

---

### ROOM_RESERVATION
USER → RESOURCE_MANAGER → SECURITY_OFFICER → APPROVED

Status:
DRAFT → SUBMITTED → IN_REVIEW → APPROVED → SCHEDULED → COMPLETED → CLOSED

---

### APPOINTMENT
STUDENT → FACULTY_SECRETARY → ADVISOR → SCHEDULED

Status:
DRAFT → SUBMITTED → IN_REVIEW → APPROVED → SCHEDULED → COMPLETED → CLOSED

---

### IT_SUPPORT
USER → IT_AGENT → IT_MANAGER → RESOLVED

Status:
SUBMITTED → IN_REVIEW → IN_PROGRESS → RESOLVED → CLOSED

---

### EQUIPMENT
USER → LAB_TECHNICIAN → RESOURCE_MANAGER → APPROVED

Status:
SUBMITTED → IN_REVIEW → APPROVED → EQUIPMENT_RESERVED → EQUIPMENT_ISSUED → EQUIPMENT_RETURNED → CLOSED

---

### INTERNSHIP_REQUEST
STUDENT → ADVISOR → INTERNSHIP_COORDINATOR → APPROVED

Status:
SUBMITTED → ADVISOR_REVIEW → COORDINATOR_REVIEW → APPROVED → INTERNSHIP_STARTED → INTERNSHIP_COMPLETED → CLOSED

---

### ACCESS_REQUEST
USER → SECURITY_OFFICER → IT_AGENT → IT_MANAGER → APPROVED

Status:
SUBMITTED → SECURITY_REVIEW → IT_REVIEW → MANAGER_APPROVAL → ACCESS_GRANTED → CLOSED

---

### PROCUREMENT_REQUEST
USER → DEPARTMENT_CHAIR → BUDGET_APPROVER → PROCUREMENT_OFFICER → FINANCE_OFFICER → APPROVED

Status:
SUBMITTED → DEPARTMENT_REVIEW → BUDGET_REVIEW → PROCUREMENT_REVIEW → FINANCE_REVIEW → APPROVED → ORDER_PLACED → DELIVERED → CLOSED

---

### EVENT_REQUEST
Student → EVENT_COORDINATOR → RESOURCE_MANAGER → SECURITY_OFFICER → APPROVED

Status:
SUBMITTED → EVENT_COORDINATOR_REVIEW → RESOURCE_REVIEW → SECURITY_REVIEW → APPROVED → IN_PROGRESS → COMPLETED → CLOSED

---

### EVENT_CREATION_REQUEST
ORGANIZER → ADVISOR → EVENT_COORDINATOR → RESOURCE_MANAGER → SECURITY_OFFICER → APPROVED

Status:
SUBMITTED → ADVISOR_REVIEW → EVENT_COORDINATOR_REVIEW → RESOURCE_REVIEW → SECURITY_REVIEW → APPROVED → EVENT_PUBLISHED → COMPLETED → CLOSED
